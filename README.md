# Quick Photo Viewer — Free for Windows

**A fast, lightweight Windows 10/11 photo viewer.** Browse images, navigate folders, use thumbnails, zoom, rotate, run slideshows, and print photos. Designed as a local-first alternative to heavy photo editors.

> **Pre-release:** Source package is being prepared. No verified Windows installer or signed release is available yet.

## Features
- JPG, JPEG, PNG, WebP, GIF, BMP, TIFF and ICO photo viewing (subject to Qt format support).
- Folder browsing, thumbnail strip, next/previous keyboard shortcuts, drag-and-drop, fullscreen and fit-to-window.
- Windows print dialog and A4 photo printing.
- Modern centred navigation and a clean desktop interface.
- Local photo viewing; your pictures are not uploaded to a server by the viewer.

## Free and Pro
**Free:** Viewing, thumbnails, zoom, rotation, slideshow, basic printing.

**Pro (planned, not on sale):** Editing plugins, batch conversion, advanced print layouts and optional face-swap integration. The Advanced tab remains locked in Free; proprietary plugins and licensing components are not published.

## Build and distribution
A Windows build created with PyInstaller includes Python and Qt dependencies; users **do not need Python installed**. The complete build folder must be distributed, not the EXE alone.

Source and GitHub Actions build files will be uploaded after final public/private component review. Please do not download binaries from unauthorised mirrors.
